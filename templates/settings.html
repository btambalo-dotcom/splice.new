Gere e baixe uma cópia do arquivo .db com todos os lançamentos, empresas, mapas, usuários, etc. Guarde esse arquivo em um local seguro.

Baixar backup (.db)

O backup funciona para os bancos SQLite usados pelo sistema (arquivo .db). Em servidores como o Render, é uma boa prática baixar esse arquivo com frequência.

Importante
  • O arquivo baixado contém todos os dados atuais do sistema.
  • Para restaurar um backup, um técnico pode substituir manualmente o arquivo de banco de dados no servidor.
  • Recomendo fazer backup antes de grandes mudanças ou atualizações.
